# 💡 Code-to-Analogy AI

**Code-to-Analogy AI** is a specialized educational tool designed to bridge the gap between technical syntax and human understanding. Instead of providing a technical explanation of code, this app uses Large Language Models (LLMs) to translate complex programming logic into simple, real-world analogies.

## 🚀 Features
- **Code Translation:** Converts any programming language snippet into a relatable story.
- **Style Selection:** Choose between different analogy styles (Simple, Professional, Funny, or Cooking-themed).
- **Powered by Groq:** Uses the Llama3 model via the Groq API for near-instantaneous responses.
- **Web Interface:** A clean, user-friendly UI built with Streamlit.

## 🛠️ Tech Stack
- **Frontend:** [Streamlit](https://streamlit.io/)
- **LLM API:** [Groq](https://groq.com/) (Llama3-8b)
- **Language:** Python 3.x
